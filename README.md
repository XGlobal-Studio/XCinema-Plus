## 🎯 Purpose & Meta Ads Policy Compliance

This website is designed strictly to **promote and showcase the XCinema Plus Android software application**. It does **not** host, stream, or facilitate piracy of movies or live television channels.

### Meta Ads Compliance Standards Followed:
1. **Zero Piracy or Copyright Circumvention Claims**: The landing page truthfully positions XCinema Plus as a personal entertainment organizer, catalog tracker, and native hardware video player.
2. **Transparent Software Distribution**: All download buttons link directly to the official open-source GitHub Releases package (`XCinema-Plus-0.0.0-alpha.0-release.apk`).
3. **Dedicated Privacy Policy & Terms of Service Modals**: In-depth disclosures that no personal data is collected or sold, and clear content disclaimers.
4. **No Deceptive Click Traps**: No fake stream players, no misleading pop-ups, and no intrusive advertising scripts.

## 🚀 Running & Building

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Accessible at `http://localhost:3000`.

### 3. Production Build
```bash
npm run build
```
Creates verified static production assets in the `dist/` folder.

### 4. Preview Production Build
```bash
npm run preview
```
